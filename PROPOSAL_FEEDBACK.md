# Project Proposal Feedback

The project is clearly described and well motivated, and comparing the model's probabilities against betting market odds is an interesting way to evaluate it. To strengthen the proposal, please make the goal more measurable. State the metrics you will use (for example accuracy, log loss, and Brier score, plus a calibration plot since you are producing probabilities) and the baselines you will beat, such as always picking the home team, an Elo or Bradley-Terry model, and the market's implied probabilities. Please also describe how you will validate: use a chronological split (for example, train on earlier seasons and test on the most recent ones) so that no information from after a game leaks into its features, and note that profiles for a week's games must only use data from prior weeks. The goal as written says "predict the winner," but the description mixes in comparisons to betting markets, so clarify which is the primary objective. The subjective-opinion feature is a concern, since it cannot be reproduced or validated and will be hard to apply to historical games without hindsight bias, so either remove it or define it as a fixed, documented rating you assign before each game. The data plan should also link the sources and confirm the package name (the maintained package is nfl_data_py or nflreadpy, and nflfastpy may be outdated), explain where you will get historical betting odds, and note that Pro Bowl selections are made after the season ends, so an elite_qb feature built from them would leak future information. With only about two months of current-season data, also explain how you will blend prior-season information to avoid noisy team profiles. Finally, the project has no timeline, so please add one with weekly tasks, and proofread for small wording issues (such as "affect" instead of "effect" and "by model's predictions").
